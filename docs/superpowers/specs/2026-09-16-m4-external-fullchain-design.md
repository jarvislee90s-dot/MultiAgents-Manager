## 1. 目标与范围

M4 是一期收尾里程碑：把 M2/M3 已在局域网验证的能力推到**外网全链路**——固定地址接入、新设备配对管控、远程期间不失联。M4 验收全绿即宪法一期验收达成。

**交付五组（T0–T4，顺序固定，前置清账先行——外网开放前必须补齐安全卫生项）**：

| # | 交付 | 来源 |
|---|---|---|
| T0 | 前置清账：SSE 连接即时断开 + TLS 确认撤回文案 | M3 评审遗留（2026-09-16 并入裁决） |
| T1 | 外部通道：命名隧道（主路径）+ 临时隧道 + cloudflared 获取 + SSE 心跳 + Tailscale 指引 | v6 P7 / B4 |
| T2 | 审批配对 + 设备花名册 | v6 P6 / B2 后半 |
| T3 | 电源保活 | v6 P11 / B5（宪法 D13） |
| T4 | 托盘远程入口 | v6 F1.1 双入口的另一半 |

**M4 不做（边界，非选项）**：系统级推送网关（ntfy/Bark，随 D17 移二期与 APK 壳同期交付）；移动端构建分包（manualChunks，二期套壳期）；任何写操作（宪法一期边界不变）；多用户账号体系。

## 2. T0 · 前置清账

### T0a · SSE 连接即时断开

- **需求**：设备被吊销或「停止远程」后，已建立的实时连接立即断开——不能只是拒绝新连接（M3 已知限制：吊销后旧连接存续期内仍收事件）。
- **输入**：吊销动作（单设备吊销 / 全部吊销 / 停止远程）。
- **输出与效果**：服务端维护「设备 → 活跃实时连接」对应关系；吊销时精准断开目标设备的全部实时连接；设备侧断连后自动重连被拒（403），走既有「回配对页」链路。吊销生效时效从「连接存续期内」收紧为**即时**。
- **边界**：只断已吊销设备的连接，其他在线设备不受影响；连接断开后即清理注册信息，不留句柄泄漏。

### T0b · TLS 确认撤回文案（M2 终审留办）

- **需求**：对外绑定前的「已具备加密前置」确认是一次性且不可在线撤回的，界面必须如实表达。
- **输入**：用户取消勾选确认复选框。
- **输出与效果**：复选框回弹为已勾选（不可取消），提示「安全确认不可在线撤回，如需撤销请改绑本机模式」；复选框旁常驻说明文案。
- **边界**：不改确认的存储语义（确认一旦置位持续生效）。

## 3. T1 · 外部通道（隧道）

### T1a · 通道区块（形态定死）

- **需求**：设置页新增「外部通道」区块，与「绑定」（127.0.0.1 / 0.0.0.0 + TLS 确认门）**独立并存**（2026-09-16 用户裁决）。
- **输入**：通道选择（关闭 / 临时隧道 / 命名隧道）。
- **输出与效果**：隧道始终连接本机回环端口，与绑定模式互不干扰——局域网直连与外网隧道可同时使用（在家走局域网、在外走隧道）。通道开启时，设置页主显示地址 = 隧道地址（固定子域或临时地址），二维码随通道地址生成；通道关闭时回退绑定地址口径（P7 已修：0.0.0.0 显示局域网 IP）。M2 已实测的绑定 + TLS 门语义零改动。
- **边界**：隧道不是绕过 TLS 门的途径——对外暴露面由通道侧加密（Cloudflare 终止 TLS），本地仍走回环；绑定 0.0.0.0 的 TLS 确认门照旧独立生效。

### T1b · 命名隧道（用户主路径）

- **需求**：填入 Cloudflare Tunnel Token 即得固定接入地址；双机双子域（mam-mac / mam-win 命名模式，域名细节见私有摘选文档）各自独立配置。
- **输入**：设置页粘贴 Tunnel Token（持久化保存）。
- **输出与效果**：远程开启且通道选命名 → 自动拉起 cloudflared（tunnel run 模式）接入本机服务；固定地址即刻可访问（部署方式与用户既有同款隧道部署一致）；进程异常退出自动重启（指数退避；连续失败 3 次即停止并桌面通知报错）；停止远程或切换通道 → 进程一并退出。
- **边界**：Token 存本机应用数据库（与配对设备表同库）；双机各填各的 Token，无任何跨机联动；cloudflared 自身的网络闪断重连之上叠加进程级守护，两层自愈。

### T1c · 临时隧道

- **需求**：零配置拉起 Cloudflare 免费隧道，扫码即用。
- **输入**：通道选临时隧道。
- **输出与效果**：自动拉起 cloudflared（quick tunnel 模式）；解析其分配的临时地址 → 设置页展示 + 二维码（含配对 token 的完整接入地址）+ 桌面通知；地址随重启变化，解析到新地址即通知。
- **边界**：临时地址不持久、不写入配置；隧道进程守护与命名隧道同一套。

### T1d · cloudflared 获取

- **需求**：首次启用隧道时自动获取 cloudflared 程序。
- **输入**：首次启用动作；当前平台与架构。
- **输出与效果**：自动从官方发布渠道下载对应平台/架构的二进制到应用数据目录（`~/.mam/bin/`），校验可执行后使用；下载失败 → 设置页给出手动放置指引（放入同一路径即可，不阻塞其他功能）。
- **边界**：不做版本管理与自动升级（cloudflared 自更新关闭）；下载源固定官方渠道。

### T1e · SSE 实时流心跳

- **需求**：Cloudflare 对空闲连接约 100 秒超时断连——外网实时流必须自带保活。
- **输入**：实时连接空闲时长。
- **输出与效果**：服务端对每条实时连接每 20 秒发送一个心跳注释帧（不产生业务事件，客户端无需处理）；看板页面长时间空闲不再被中间层断连。
- **边界**：心跳只在服务端连接层发送，与状态扫描节奏（零订阅者免扫描）互不影响。

### T1f · Tailscale 指引

- **输出与效果**：设置页帮助区给出 Tailscale 用户接入指引文案（链接 + 步骤说明），不写任何代码。
- **边界**：四通道模式（直连 / 临时 / 命名 / Tailscale）共用同一套配对与安全语义（v6 P7 既定）。

## 4. T2 · 审批配对 + 设备花名册

### T2a · 请求接入流

- **需求**：新设备（未配对）打开接入地址，看到「请求接入」页而非死路。
- **输入**：新设备访问；设备名（自动取浏览器标识，可修改）。
- **输出与效果**：页面发起接入请求 → 桌面 MAM 弹系统通知（点击直达配对面板）+ 配对面板出现待审批项（设备名 / 来源 IP / 浏览器标识 / 剩余有效时间）；请求 5 分钟内有效，过期自动消失；待审批队列并发上限 3，同一来源 IP 同时仅 1 个待审批请求，超限提示稍后再试。
- **边界**：请求页对未配对设备可见，但不暴露任何会话数据；请求只在内存队列（重启即清，不落库）。

### T2b · 双批准路径

- **需求**：批准方式两种，等效授权（v6 P6 既定）。
- **输入**：桌面用户操作 / 手机输入确认码。
- **输出与效果**：
  - **路径一 · 桌面批准**：待审批项点「批准」→ 设备侧数秒内拿到凭证进入看板；
  - **路径二 · 4 位确认码**：待审批项**自动显示** 4 位确认码，手机在请求页输入该码即等效授权；单请求限试 3 次，错满 3 次请求作废需重新发起。
- **边界**：两路径先到先得（一条路径生效后请求即消费）；批准/作废均从队列移除并留痕。

### T2c · 设备上限（全配对入口统一强制）

- **需求**：设备上限默认 3 台（设置可改），满员需手动腾位（v6 P6）。
- **输入**：任意配对入口的新设备授权动作（桌面批准 / 4 位码 / 直通扫码）。
- **输出与效果**：已达上限时——审批路径「批准」按钮禁用并提示去花名册腾位；4 位码输入返回「设备已满」；直通扫码拒绝并回「设备已满」。**三个入口同一道门**（设计自审修正：若仅审批路径设限，直通扫码可绕过上限）。
- **边界**：上限按「有效设备」（未吊销）计数；吊销即腾位。

### T2d · 设备花名册

- **需求**：设置页可视化管理已配对设备。
- **输入**：花名册面板操作。
- **输出与效果**：设备列表——名称 / 配对时间 / 最近活跃时间 / **在线状态点**；单设备吊销（吊销后按 T0a 即时断连）；全部吊销；上限配置项。在线口径 = **存在活跃实时连接 或 最近 30 秒内有过闸记录**（设计自审修正：纯实时连接的设备不再发轮询请求，仅看过闸时间会误判离线）。
- **边界**：花名册只展示设备元数据，不含任何会话内容。

### T2e · 审计留痕

- **输出与效果**：配对请求 / 批准 / 4 位码失败 / 吊销 / 停止，逐条留痕（时间、设备、来源 IP、动作、结果），日志可追溯。
- **边界**：留痕只在本机，不外发。

### 直通配对（M2 已交付，M4 不动其语义）

一次性二维码临时分享保持现状，仅叠加 T2c 的上限门。

## 5. T3 · 电源保活

- **需求**：远程开启期间电脑不得休眠失联（宪法 D13）。
- **输入**：远程开关状态；保活开关（设置页，默认开）。
- **输出与效果**：远程开启且保活开 → 持有系统电源锁（阻止系统空闲睡眠与磁盘休眠，**屏幕可熄**）；远程关闭或应用退出 → 释放。Windows 侧：代设硬盘休眠为「永不」，代设前先保存原值，关闭远程时**还原原值**。
- **边界（界面明示）**：macOS 合盖仍会休眠（系统限制）；macOS 系统睡眠锁在电池模式下不完整生效（接电源才完整）、Windows 临界电量强制睡眠不可阻止——两条边界文案写入设置页。
- **边界**：保活跟随远程开关，不提供「保活但远程关」的独立状态。

## 6. T4 · 托盘远程入口

- **需求**：远程开关双入口的托盘一半（v6 F1.1）。
- **输入**：托盘菜单点击。
- **输出与效果**：托盘菜单新增「远程接入」开关项（勾选态 = 当前远程状态，与设置页同一状态源、同一开关链路）；下方常驻展示当前对外地址（通道开启时为隧道地址，否则为绑定口径地址），点击复制；开关失败（如 0.0.0.0 未过 TLS 确认门）→ 勾选态回弹 + 桌面通知报错。
- **边界**：托盘仅开关与地址展示，不放配对面板（配对管理仍在设置页）。

## 8. 非功能需求

- **安全**：吊销即时生效（T0a）；配对三入口统一上限门（T2c）；通道不弱化 TLS 确认门（T1a）；配对动作全程留痕（T2e）。
- **性能**：隧道不劣化既有 2 秒实时口径；心跳帧零业务开销。
- **可靠性**：cloudflared 两层自愈；地址变化通知；应用退出清理子进程与电源锁（不留孤儿进程、不失电源锁）。
- **兼容**：M2/M3 全部已实测行为零回归（绑定 / TLS 门 / 直通配对 / SSE / 降级轮询 / 看板 UI / 会话内容与文件预览）。

## 9. 验收清单（M4 出口 = 宪法一期验收）

外网真机（手机蜂窝网络，非局域网）：

1. **固定地址接入**：手机蜂窝网络访问固定子域 → 看板与任意会话内容可用（T1b）。
2. **实时提醒**：页面开着，桌面杀掉一个 agent 会话 → 手机 2 秒内横幅 + 提醒音（外网环境复验 M3 口径，D17：页面开时 SSE）。
3. **审批配对全流程**：新设备请求 → 桌面批准进入；另设备请求 → 输 4 位码进入；错 3 次作废；请求放置 5 分钟过期；满员时三入口全部拒绝并提示腾位（T2）。
4. **吊销即时断连**：花名册吊销在线设备 → 该设备看板立即断开回配对页；「停止远程」→ 全部设备 403（T0a + T2d）。
5. **quick tunnel 断网自愈**：临时隧道模式断网数秒再恢复 → 看板自动恢复数据流；地址变化有通知（T1c）。
6. **电源保活**：Windows 实机远程彻夜开启不失联；关闭远程后硬盘休眠设置还原为原值（T3）。
7. **托盘入口**：托盘开关与设置页状态一致；地址可复制；0.0.0.0 未确认时托盘开启失败有报错回弹（T4）。
8. **零回归**：桌面既有功能全部不变 + 全量门禁绿（Rust / 前端测试、双端构建、clippy / fmt / lint）。

局域网真机补充：临时隧道全程（拉起 / 二维码扫码 / 地址通知）；T0b 撤回文案交互。

## 10. 与 v6 的差异及依据（2026-09-16 裁决）

| 差异 | 依据 |
|---|---|
| 推送网关（v6 P10b / C3）移出一期 | 宪法 D17（用户裁决：随 APK 壳二期同期交付） |
| 移动端构建分包移出一期 | D17 附注（二期套壳期） |
| M3 评审遗留 SSE 注册表、TLS 文案并入 M4 | 2026-09-16 用户裁决（原登记为「M4 候选」） |
| 外部通道独立区块（非四模式互斥单选） | 2026-09-16 用户裁决 |
| 在线口径 = 活跃实时连接 ∨ 最近过闸 < 30s | 设计自审修正（纯实时连接设备不再轮询，仅看过闸会误判离线） |
| 设备上限三入口统一强制 | 设计自审修正（否则直通扫码可绕过上限） |
