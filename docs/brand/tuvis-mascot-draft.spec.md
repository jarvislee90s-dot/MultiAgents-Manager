## 小尺寸降级规则

- **≤48px**（列表头像、DMG 桌面图标小态）：只用「头 + 耳 + 面罩」，去身体/手臂/灯
- **≤16px**（托盘）：只保留「胡萝卜灯」单符号（橙萝卜 + 当前状态色辉光），三态即三个托盘图标
- 托盘三态 = 状态灯三态参数，直接复用上表

## IP 安全边界（防跑偏，三不要）

1. 不用红+金主色（铁人签名色）
2. 胸灯不做三角形/弧形反应堆造型——只借「发光圆灯」氛围，造型 = 胡萝卜（原创独占符号）
3. 耳朵保持打开 + 戴科技环，禁止「暗色头套 + 竖直尖耳」剪影（蝙蝠侠撞型）
