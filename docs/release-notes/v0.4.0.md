# ✨ v0.4.0 更新 — ZCode 支持 + 双开跳转直达

本版本三大主题：**ZCode 第七工具支持**、**同项目双开一键直达**、**看板信息可读性**。另附一批监控解析与深链派发修复。

---

## 🤖 ZCode（智谱桌面 AI 编程助手）完整接入

第七个受监控工具，macOS / Windows 双端同一套语义：

- **会话监控**：从 ZCode 本地双 SQLite 库聚合会话，每会话一卡、红绿灯状态与其他工具一致；状态按消息流顺序推导（尾部工具调用 = 运行中），`<todo>` 等内部记账消息不干扰判定
- **子代理仲裁**：主会话静默等待子代理执行 ≠ 卡死——子会话仍在活跃时保持「运行中」，只有后代也停更才降级「等待」；「N 个子代理」计数只统计当前活跃的
- **跳转**：点击卡片**直接聚焦 ZCode 唯一窗口**——无确认弹窗、不新建会话、不拉起转发进程（ZCode 为单窗口多标签应用，窗口零歧义）
- **资源管理**：skill 分发到 `~/.zcode/skills/`（**已实测被 ZCode 识别**，复制任意技能目录改名即可被拾取）+ MCP 配置只动 `mcp.servers` 子树，未知键与键序原样保留

> 设计说明：ZCode 的工作区深链（`zcode://workspace/open`）经实机验收后有意不接入——它的落点是"新会话编辑器"而非已有会话，且每次派发都会弹信任确认。跳转改为窗口聚焦后，点击即达。

## 🎯 同项目双开，一键直达

同个项目开两个终端（或两个会话）时，点击卡片**直接锁定对应窗口**，不再弹候选选择器：

- **Kimi / OpenCode**：终端窗口标题与会话标题归一化比对（kimi 取 `state.json` 会话标题，OpenCode 取数据库标题），唯一命中即锁定
- 会话标题经看板 / 通知 / 桌宠 / 历史记录**全部跳转入口统一透传**，从任何入口点进来都享受同一套匹配
- 根因修复：Kimi CLI 写入的整数毫秒时间戳导致会话标题整个解析失败（标题回退成 `session_` 前缀，匹配永不命中）——现兼容数值 / 字符串双形态
- 根因修复：OpenCode 同目录两个终端只有一个会话可见（两个进程都认领最新一条会话、旧的被遮蔽）——现按目录配对到各自进程

## 🗂️ 看板信息可读性

- **项目名显示预算**：中文名封顶 10 字、英文名封顶 15 字符（宽度折算），截断点固定、不随窗口宽度漂移；完整名称悬停可见
- 卡片顶行布局调整：项目名优先完整显示，会话标题压缩为灰色尾巴、空间不足时先让路——超长任务标题不再把项目名挤成单字

## 🔧 其他修复

- **深链派发机制**：改用 ShellExecuteW 优先派发（`cmd /C start` 会把成对 `%` 当环境变量展开、破坏编码 URL），WorkBuddy / Codex 的会话级深链同样受益
- **MCP 面板**：openclaw / kimi / workbuddy 的 MCP 读取此前一直落「未知工具」——读取链路注册表化，全部工具可达
- Codex 会话标题键前缀 8 → 12 位，消除同一分钟内创建会话的碰撞
- MCP 导入溯源、前端工具清单等三处硬编码工具列表一并注册表化
