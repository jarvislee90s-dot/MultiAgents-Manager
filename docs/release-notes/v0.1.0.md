# 🎉 MultiAgents Manager v0.1.0 首次发布

MultiAgents Manager 正式发布！一站式管理 Claude Code、Codex CLI、OpenCode、OpenClaw 的桌面应用。

---

## ✨ 核心功能

### 📊 会话监控看板

实时红绿灯状态看板，一目了然掌握所有 AI 编程工具的运行状态。

- 🔴 **红色** — 等待用户输入
- 🟡 **黄色** — 处理中 / 思考中  
- 🟢 **绿色** — 空闲 / 已完成

支持的 AI 编程工具：

| 工具 | 检测方式 | CLI | APP |
|------|---------|-----|-----|
| Claude Code | JSONL + Hook 事件 | ✅ | — |
| Codex CLI/APP | JSONL + Hook 事件 | ✅ | ✅ |
| OpenCode | SQLite 数据库 | ✅ | — |
| OpenClaw | state.json | ✅ | — |

- 显示项目名称、Git 分支、最后消息预览、CPU 占用、运行时长
- 按优先级自动排序：等待中 → 运行中 → 空闲
- 系统托盘图标反映聚合状态

### 🔔 桌面通知与提示音

- 状态颜色变化时自动发送桌面通知（带去重机制）
- Web Audio API 提示音，无需音频文件
- 通知/提示音可在设置中独立开关
- 通知可点击，附带「查看会话」动作直接跳转终端

### 🖥️ 快速跳转终端

点击会话卡片即可瞬间聚焦对应终端标签页：

| 终端 | 状态 |
|------|------|
| iTerm2 | ✅ |
| Terminal.app | ✅ |
| tmux | ✅ |
| Wayland | ⚠️ 优雅降级提示 |

### 📦 扩展资源统一管理

Skill / MCP 服务器 / 插件的统一仓库，一键映射到各工具：

- **Skill** — 符号链接映射到各工具的 skill 目录
- **MCP 服务器** — 自动格式转换（JSON / TOML / JSONC）
- **插件** — 文件 + 配置混合管理
- 首次启动自动导入已有 skill
- 双视图管理：按资源类型 / 按工具

### 🎭 预设组一键切换

将 Skill + MCP + 插件打包为命名预设组：

- 一键应用到任意工具，自动适配各工具的配置格式
- 部分成功处理：失败项报告错误，不回滚已成功项
- 冲突检测：跳过已存在的资源
- 系统托盘菜单集成，快速切换预设

### 🧩 子 Agent 级资源分配

为多 Agent 工具（Hermes、OpenCode 等）的子角色分配资源子集：

- 子 Agent 分配受工具级启用范围约束
- 工具级禁用自动级联到所有子 Agent

### 🌐 国际化

- 支持中文、English
- 自动检测系统语言，可在设置中切换

### 🎨 主题

- 跟随系统自动切换暗色/亮色模式
