# 🎉 v0.5.5 更新 — 项目更名「兔维斯 Tuvis」+ 子 Agent 运行观察台

本版本有两件大事：项目正式更名为**兔维斯（Tuvis）**，以及会话详情新增**子 Agent 运行 chip 与观察台**。

---

## 🐰 项目更名：兔维斯（Tuvis）

「Tu」= 兔，「vis」致敬 Jarvis 的尾音——一只不知疲倦的机甲兔，替你盯着所有 Agent。
从此以后，MultiAgents-Manager（MAM）就叫 **Tuvis / 兔维斯**了：仓库地址、安装包名、
应用名称全部换新（旧链接会自动跳转，收藏夹不用改）。

## ⬆️ 升级须知（重要，请先看这里）

本版本更换了应用身份与数据目录，**旧版应用内的「检查更新」已不可用**，请手动下载新版安装包：

1. **先卸载旧版 MultiAgents Manager**，再安装本版——新旧是两个应用登记，直接装会双装（两个托盘图标）；
2. 打开新版，你的**所有数据自动跟着走**：首次启动会自动把 `~/.mam` 迁移为 `~/.tuvis`
   （会话、用量账本、技能、MCP 配置一个不少；万一自动迁移失败，旧数据原地保留，
   手动把 `~/.mam` 改名 `~/.tuvis`、再把里面的 `mam.db` 改名 `tuvis.db` 即可）；
3. 用 Codex 的话：首次启动后需在 Codex 终端输入 `/hooks`，**重新信任一次**兔维斯条目
   （注册路径随更名变化，信任哈希随之更新，一次性）。

---

## 🤖 子 Agent 运行 chip 与观察台（Claude Code 全量支持）

会话在跑什么子 agent，现在一眼可见：

- **会话卡片实时 chip**：正在运行的子 agent 名字、时长走字、token 消耗，点击直达详情；
- **「子 Agent」看板**：会话详情里的平级面板，按派发顺序排列——运行中绿点走字，
  完成灰点定格（时长 / token 定格），点卡片进入执行过程；
- **执行过程详情**：任务原文、思考过程（默认折叠）、每个工具调用与结果（折叠单行）、
  输出正文；活跃时 5 秒一拍自动刷新、贴底跟随，完成后定格快照；
- **「子 Agent 回报提醒」独立开关**（设置页，默认开）：子 agent 完成回报要不要唤醒你，
  与主会话提醒分开控制。

## 🔧 修复

- **子 agent 完成后 chip 不消失**：Claude Code 的 teammate 空闲通告此前不被识别，
  完成状态永挂——现在完成即消失、续跑即复现（真机验收通过）；
- **状态黄绿抖动期的连环弹窗**：主会话状态抖动时不再每次都弹提醒
  （同方向跃迁 60 秒节流，红色 / 等待批准不节流）；
- **重开历史会话不再重复弹信任确认**：已信任目录做大小写/分隔符归一识别。
