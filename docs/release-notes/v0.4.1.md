## 🟣 dsh 第八工具支持

dsh 是 web 宿主形态的 DeepSeek 编程助手，本版本全链路**只读**接入（MAM 不写入 `~/.dsh` 任何会话数据）：

- **会话看板**：双数据源聚合（projcache 元数据 + zstd 多帧事件日志），每会话一卡、24h 活动窗口、子 Agent 过滤；三代际日志自动取最新，损坏尾帧容错
- **三色状态**：等待批准（红，含审批待决）/ 运行中（黄）/ 完成（绿）；`session.lock` 交叉判定识别「写入者已死」的中断会话，审批 `asked → decided` 决议后自动恢复完成态
- **标题与预览**：注入帧（agent-instructions / skill-catalog）过滤、工具帧回落、真人输入优先展示
- **一键跳转**：点击卡片聚焦浏览器中的 dsh 标签页（已关闭则免登录新开），跳转成功自动收起看板（macOS）
- **资源页**：skill 目录接入统一管理（启停建链）；MCP / 插件经实机探测定案显式「暂不支持」——资源页现按工具能力标志如实渲染支持度

> 已知限制（已裁决）：MAM 重启后，空闲超过 24h 且回合未闭合的 dsh 会话（红·中断 / 红·等待批准）不会重新上板；MAM 持续运行期间不受影响。

## ⚡ 会话扫描性能大修

- **重扫描不再冻结界面**：会话扫描移出主线程；主窗口与桌宠的并发轮询共享最近一次快照（单飞护栏），不再堆叠重复扫描
- **fsync 风暴消除**：会话状态未变化时跳过写库——真机实测持续 ~69% 单核占用归零；长青卡的离板保留语义经评审修复完整保留（不会误清、不会重打未读角标）
- **dsh 扫描三层预算**：未变更文件零重读（内容缓存）+ 锁探测仅在回合未闭合时执行（12.5s/轮 → 0.12s/轮）+ 冷启动 mtime 预过滤（超窗历史日志不打开不解压）
