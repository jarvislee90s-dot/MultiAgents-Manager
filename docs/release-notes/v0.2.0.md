# ✨ v0.2.0 更新 — Foxbell 桌宠来了 🦊

本版本两大主题：**Foxbell 桌宠**完整移植上线，以及 **Kimi Code** 第五工具支持。

---

## 🦊 Foxbell 桌宠（新功能）

独立悬浮桌宠窗口，完整移植自 DSH 插件 `dsh-foxbell-pet` v1.3.0：会说话的小狐狸常驻屏幕右下角，实时监控所有会话状态。

### 状态监控与卡片

- 桌宠头顶为每个活跃会话显示状态卡片（最多 6 张 + "+N 更多"），灯色与看板语义完全一致：🔴 等待操作 / 🟡 运行中 / 🟢 完成未读
- 点卡片直接跳转对应终端；绿灯卡片点开即消，再次完成重新亮起
- 会话消失后卡片保留 60 秒再清理

### 语音提醒（自带 31 条语音）

| 语音组 | 触发时机 |
|---|---|
| 🔴 approval（撒娇催促） | 出现等待操作（10 秒限频防刷屏） |
| 🟢 done（求夸/元气） | 任务完成（变绿） |
| 💬 general（闲聊） | 双击桌宠随机说一句 |
| 🔇 运行中不发声 | — |

字幕与语音时长自动对齐；静音与字幕是两条独立开关（静音≠静止，动作照播）。

### 交互与手感（1:1 复刻原版）

- **动画**：9 组逐帧时长动画 + 空闲 6 秒后 16 向环顾扫视；任务状态驱动姿态（等待 > 审查 > 工作）
- **拖拽物理**：松手重力坠落、水平抛掷惯性、落地压扁回弹 + 补跳（可关）
- **单击**挥手不出声、**双击**说话、**右键**菜单：出声/字幕/物理/悬浮最前开关、大小三档（小/中/大，等比例缩放）、双击/红灯/绿灯三场景动作绑定（6 种动作可选，子页实时预览）、隐藏、关于

### 与看板的联动

- **完成提示音接管**：桌宠开启时由桌宠语音替代看板提示音（桌宠静音则整体静默）
- **通知浮窗抑制**：桌宠悬浮最前时不再弹右下角浮窗（头顶状态栏常显）；非置顶时照常弹窗
- **四个入口**：看板设置「桌宠」分区、主窗口 🦊 快捷按钮、系统托盘、右键菜单，状态互通

> ⚠️ 已知限制：点击穿透未实现（Tauri 尚无相关 API），桌宠透明矩形区域会遮挡其下方应用的点击；请将桌宠拖到不遮挡常用区域的位置。
