# 🔧 v0.5.1 更新 — 应用内升级更好用，免域名向导在 Windows 上跑通了

本次主要做两件事：**应用内升级体验重做**、**「外部域名（免域名）」向导修掉 Windows 实测发现的问题**。

从 v0.5.0 直接升级即可，没有数据迁移，也没有任何设置需要改。

---

## ⬆️ 应用内升级

- **能收到测试版通知了**：以前只提醒正式版，现在 beta 测试版也会按版本号提醒
- **升级弹窗重做**：能看到这次更新了什么；三个按钮任选——立即升级 / **忽略这个版本**（以后不再自动弹）/ 稍后
- **有更新时标题栏出现角标**：就算点了「忽略」，也随时能找到升级入口
- **失败时告诉你原因**：检查或安装失败不再只显示「失败」两个字，网络、代理等问题第一眼能看懂
- **Windows 上升级更稳**：升级重启前会把隧道、Tailscale 等后台状态正常收尾；升级残留的临时文件自动清理

---

## 🛰 外部域名（免域名）向导 · 修掉 Windows 实测发现的问题

v0.5.0 上线了「不用买域名也能拿到固定访问地址」的一键向导。发布前我们在一台 Windows 电脑上把它从零完整走了一遍，发现并修掉了这些问题：

- **Tailscale 装到非默认位置也能认出来**：以前只认默认安装目录，装到别处（尤其路径带中文）会被误判成「没装」，向导就反复下载安装；现在会从系统服务登记里找到真实位置
- **登录那一步有能点的东西了**：以前向导不会帮你发起登录，页面上一片空白；现在会主动拿到 Tailscale 的授权链接做成按钮，点开在浏览器里登录就行（MAM 只负责递链接，不代登录、不碰你的账号）
- **提前说清「安装路径可以自己选」**：Tailscale 安装时会弹安装向导让你选路径，现在会提前告诉你「用默认路径最省事；装到别处也可以，记住装哪了就行」
- **撤下 Windows 的「未实机校验」提示**：整条流程已经真实跑通，不再挂着黄色警示
- **下载、安装过程有进度反馈**，不再显示假百分比；向导底部新增「Tailscale 是什么」的说明和官网链接
- **卡片名字变短**：「外部域名（免域名）」→「外部域名」，窄窗口下不再被截断
