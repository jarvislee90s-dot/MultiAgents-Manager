# ✨ v0.3.0 更新 — 自定义桌宠 + WorkBuddy 支持 + 工具勾选管理

本版本三大主题：**桌宠格式开放**（导入你自己的宠物）、**WorkBuddy 第六工具支持**、**工具勾选管理**。另附一批 APP 跳转与会话监控稳定性修复。

---

## 🐾 外部桌宠开放：带上你自己的宠物

桌宠格式正式开放，不再只有 Foxbell。迁移自 Codex / petdex 宠物生态的完整格式：

- **两种导入方式**：本地 zip / 目录导入，或从内置 **Petdex 在线宠物仓库**浏览下载（下载体积与响应体均有上限防护）
- **全量校验**：manifest 结构、精灵图帧率与尺寸、语音清单逐项验证，不合格即拒绝并给出结构化错误（中英双语提示）；IPC 宠物 ID 做路径逃逸防护
- **管理面板**：导入 / 描述编辑 / 重命名 / 删除 / 一键切换，宠物窗口**热切换**无需重启；删除或切换后活动宠物自动恢复
- **能力门控**：不带语音的宠物自动降级为纯动画模式（瞬态动作保留、字幕照常），语音能力缓存双向同步
- 本批次一并落地 13 项前端 UX 打磨与后端加固（staging 清扫先行、zip 依赖统一 v4 等）

> 想做自己的宠物？参照 Foxbell 的目录结构打包 manifest + 精灵图 + 语音即可。

## 🛠️ WorkBuddy 第六工具支持

CodeBuddy 生态的 WorkBuddy 桌面 APP 完整接入，macOS / Windows 双端同一套语义：

- **会话监控**：心跳目录驱动的进程发现（`~/.workbuddy/sessions/`），严格 UUID 校验 + prewarm 池过滤，红绿灯状态判定与其他工具语义一致
- **Windows 实测校准**：盘符路径 mangle、JSONL 目录扫描兜底、90 秒心跳新鲜度阈值，均按真机实测修订
- **资源管理**：Skill 目录（`~/.workbuddy/skills/`）与 MCP 配置（`~/.workbuddy/mcp.json`，JSON 格式）接入统一仓库与预设组
- **官方品牌图标**：看板、通知、工具管理各行到位

---

## 🔗 APP 类工具：深度链接直达 + 持久未读卡

APP 形态的会话不再是"只可远观"：

- **会话级深度链接第一优先**：`workbuddy://chat/<sessionId>`、`codex://threads/<threadId>` 直达具体会话；派发前校验协议 handler、派发后验证前台化，探不明或失败自动落 **APP 级前台保底**（macOS AppleScript / Windows 近祖聚焦），且**不误标已读**
- **Windows 深度链接支持**：含 MSIX 协议注册形态的判定修正（只查注册表 command 会产生假阴性）
- **持久未读卡**：APP 类会话转绿后卡片跨 MAM 重启保留；点击跳转或手动关闭后消失；宿主进程退出时该工具卡片全部清理
- **手动关闭**：看板与桌宠的状态卡新增 X 关闭按钮
- 一批跳转链修复：冷启动深度链接链进程快照刷新、AppleScript bundle 字面量转义、宿主进程匹配收紧、历史跳转走 deep-link 优先

## ✅ 工具勾选管理（设置页新分区）

哪些工具被 MAM 管理，现在由你决定：

- **行式开关列表**：每行 = 图标 + 名称 + 安装状态 badge + 开关；本地暂存、**批量保存**，保存前确认弹窗列出还原/回溯清单，未保存离开自动拦截
- **取消勾选 = 彻底还原**：符号链接还原为真实文件、MCP 条目从工具配置移除、未读卡清空；**SSOT 仓库与分配关系全部保留**，重新勾选按原分配整体重建——部分失败自动回滚，重新保存即幂等重试，不再需要"先关再开"
- **彻底隐藏**：未勾选工具的会话扫描跳过、通知静音、资源/预设界面不出现，相关写命令返回明确错误（结构化错误码渲染为中英文本地文案）
- **保存体验打磨**（issue #36 全 8 项）：命令层守卫全覆盖、保存异步化不再冻结窗口、还原结果按「保持/丢失」分级提示、`~/.claude.json` 写回不再按键序重排整个文件

## 🧯 稳定性与体验修复

- **会话监控**：标题读取回退、兜底扫描缓存、pid 交叉校验、每轮复用 SQLite 连接；心跳观察持久化实现跨重启补偿；已读墓碑持久化，杜绝「已读复活」

- **桌宠**：终端会话关闭立即清理对应卡片；失败音频探测止停；活动宠物删除/切换后自动恢复

## ⚠️ 已知限制

- macOS / Windows 构建未签名，首次打开需在系统安全设置中允许
