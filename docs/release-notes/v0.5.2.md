# 🔧 v0.5.2 更新 — 修掉 Windows 连环黑窗，挂 VPN / 被 DNS 污染也能检查更新了

本版本是三个实测问题的修复集，没有新功能，升级无感。

---

## 🖥 修掉「连续黑色终端弹窗」

上一版在 Windows 上如果开着「外部域名」通道，桌面会不停弹出黑色终端窗口（每 5–60 秒一次），
很影响操作。原因：MAM 每次探测 Tailscale 状态都会启动一个命令行程序，没加「不创建窗口」
的标志，于是每次都闪一个黑框。已修——启动 `tailscale login`、安装程序、cloudflared 隧道
这些地方也一并补上了。

> 这个问题从 v0.5.0 就存在；开发时从终端启动应用不会复现（子进程直接复用终端），
> 只有安装版会显现，所以现在才被抓到。

---

## 🌐 检查更新：挂 VPN、DNS 被污染的环境都能用了

上一版的「检查更新」在国内网络环境经常失败，原因有两层：

- **挂 VPN 时**：MAM 现在会正确读取 Windows 系统代理（你的 VPN 设置的代理地址），
  经代理访问 GitHub——这条链路已用独立探针逐一验证过；
- **没挂 VPN 时**：国内网络对 GitHub 的域名解析常被污染（连上的是假服务器）。
  现在检查更新失败后会自动切换**兜底通道**：用阿里/腾讯的加密 DNS（DoH）查到 GitHub
  的真实地址，直连访问——实测这条路径在污染环境下秒通。

修复后，检查失败时的提示也会带上**具体原因**（证书不对 = DNS 污染 / 连代理被拒 =
VPN 没在跑 / 超时 = 网络慢），不再是一句笼统的「请求失败」。

## 🪟 升级弹窗不再「没头没尾」

以前弹窗里的「更新说明」开头是一大段**下载清单**（`xxx.dmg`、`xxx-setup.exe` 那些）——
那是给去网页手动下载的人看的，在应用内升级的弹窗里毫无用处；真正的更新内容被顶到很下面。
现在弹窗直接从**更新内容**开始，文字也不再居中，一眼能看到这版改了什么。想看完整信息，
点「在 GitHub 查看」即可。
