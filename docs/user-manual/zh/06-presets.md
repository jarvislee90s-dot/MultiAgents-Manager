# 预设组

预设组的独占应用、恢复默认、暂存区、常驻锁、专属绑定与一致性体检

## 概述

预设组把一组 Skill / MCP / 插件打包成一个「套件」，一键应用到某个 AI 编程工具。它解决的问题是：不同任务需要不同的工具组合（前端开发一套、数据处理一套），手动逐个开关既繁琐又容易遗漏。预设组采用**独占语义**——应用后，该工具只看得到预设内的资源加上你标记为「常驻」的资源，其余一律让路；关闭预设则恢复到应用前的状态。

## 核心概念

- **独占套件**：应用预设 = 「停用/暂存现有资源 → 启用预设内资源」的组合动作。应用后工具的资源面 = 预设内资源 + 常驻资源，二者之外全部退场。
- **通用预设**：只包含 MAM 仓库资源（Skill / MCP / 插件），可以应用到任何已启用的工具。
- **工具私有预设**：绑定单一工具，除 MAM 资源外还可以包含该工具的**原生技能**（直接装在工具目录里、不经 MAM 仓库的技能）。
- **同工具至多开启一个**：对同一个工具开新的预设时，旧预设自动翻关。全部关闭后，工具回到应用预设前的原生状态（MAM 会为每次应用拍一份「基底快照」，关闭即按快照还原）。

## 预设组列表

资源页的预设区采用**双分区**呈现：

- **通用预设**：不绑定工具的预设；每张卡片下方为每个已启用工具各提供一个滑块开关。
- **工具私有预设**：按绑定工具分组展示（组头带工具图标）；只有绑定工具一枚开关。

每张预设卡片包含：预设名称、描述摘要（单行截断）、资源条目计数徽标（如 `3`）、每个可用工具的滑块开关、删除按钮。点击卡片任意空白处可进入编辑弹窗。

**删除保护**：预设正在应用中时，删除会被拒绝并提示「该预设组正在应用中，无法删除；请先关闭后再试」（编辑保存同样受此保护）。先把该预设在这个工具上关掉，再执行删除。

## 应用与恢复（滑块开关）

- **开 = 应用**：打开开关会先弹出**确认弹窗**，dry-run 预览本次应用的完整差异，共五段（空段自动隐藏）：
  1. **将启用**——专属过滤后真正会启用的资源；
  2. **被过滤**——因专属绑定不适配当前工具而被跳过的项，逐条注明原因；
  3. **将停用**——会被清扫掉的 MAM 资源；
  4. **将暂存**——会被移入暂存区的原生技能（逐个点名）；
  5. **常驻豁免**——不在预设内但受常驻锁保护、不会被触碰的资源（仅显示计数）。

  确认后才真正执行，完成后以 toast 汇报「已应用 N 项，停用 N 项，暂存 N 项」。
- **关 = 恢复默认**：直接执行（无确认弹窗），按基底快照把工具还原到应用前的状态，toast 汇报恢复数量；有冲突时以警告 toast 列出明细。
- **白板模式**：如果预设没有任何可启用项（例如只为了「清空现场」），确认弹窗会显示顶部强警示「白板模式：本次应用不会启用任何资源，仅停用/暂存现有资源（常驻项豁免）」，确认按钮转为红色警示样式——仍然允许继续，只是明确告诉你后果。
- 若预设含当前工具不支持的资源类型，对应开关会被禁用并提示「暂不支持」；但**已开启的开关永远可以关**（关是安全的恢复动作）。

## 暂存区

应用预设时，工具里**非常驻**的原生技能目录会被整体移入暂存区 `~/.mam/stash/<工具>/skills/`（同盘移动、零拷贝）；关闭预设恢复默认时自动回移原位。暂存有账本（stash_journal）记录，崩溃后重启可凭账本对账恢复。

- **同名占位冲突**：回移时如果原位已存在同名目录（例如你在预设会话期间手动装了同名技能），MAM **不会覆盖**，该项留在暂存区并提示冲突，等你人工处理。
- 没等到恢复的暂存项也会出现在体检卡片的「残留暂存条目」段，可逐条手动「回移」。

## 常驻锁

有些资源你希望**任何预设都动不了**——比如核心 MCP、必备技能。在资源卡片的工具行上有一个锁开关（常驻锁），打开后该资源对此工具即为「常驻」，卡片上出现「常驻」徽标。

- 独占清扫**永不触碰**常驻资源：既不停用、也不暂存。
- 应用确认弹窗的「常驻豁免」计数就是本次被这把锁保下来的资源数。

## 专属绑定

某些资源依赖特定工具的环境（如依赖某工具的 App 或配套 MCP），把它放进其他工具只会出问题。专属绑定让它只在允许的工具中可用：

- 资源名称旁的橙色**「专属」徽标**表示已绑定；点击徽标打开编辑弹层，可勾选**允许工具**并填写**专属原因**（建议写明为什么，例如「依赖 codex App + computer-use MCP」）。清空勾选保存 = 清除绑定，恢复通用。
- 不适配工具的启停按钮会**置灰**，悬停显示原因。
- 资源行的「全部启用」批量操作会**自动跳过**不适配工具，完成 toast 中的「跳过」计数即来自这里。
- **SKILL.md 声明自动识别**：技能的 SKILL.md frontmatter 若声明了专属工具（识别键 `supported_agents` / `agents` / `compatible_tools` / `tools`，值支持 YAML 数组 `["a", "b"]` 或逗号串 `"a, b"`），导入时会弹确认框询问是否按声明写入专属绑定；存量技能的声明则会列在体检卡片的「待确认专属建议」段，逐条「设为专属」或「忽略本轮」。自动识别**仅建议不强制**，手动绑定永远是真值源。
- **已知限制**：块列表风格声明暂不识别——即 `tools:` 后换行缩进 `- 项` 的写法（`tools:\n  - claude`）会被视为未声明，请改用数组或逗号串写法。

## 一致性体检

预设独占与启停都依赖「账本（数据库）↔ 磁盘（符号链接/目录）」的一致。资源页与设置页都提供**一致性体检**卡片，角标显示未决差异数，点击「立即体检」随时重扫。它聚合四类信息：

**① 账本-磁盘漂移**（按工具分组，四类徽标）：

| 级别 | 名称 | 含义 |
|------|------|------|
| L1 | 缺链 | 账本记着启用，磁盘上链接却不在了 |
| L2 | 占位 | 应该是链接的位置放了真目录，且账本记着启用 |
| L3 | 多链 | 磁盘上有指向 MAM 仓库的链接，账本却没记启用 |
| L4 | 外链 | 链接指向 `~/.mam` 之外的目标（不归 MAM 接管） |

每行提供三种处置：

- **a 以账本为准修磁盘**——L1 重建链接、L2 校验一致后替换为链接、L3 清除链接；
- **b 以磁盘为准回写账本**——接受磁盘现状，把账本改成与之一致；
- **c 暂不处理**——本轮流收起（下次体检会重新出现）。

两条安全底线：**L2-a 若发现真目录与共享仓库内容不一致，自动转「需人工处理」，MAM 绝不删除真目录**；L4 无论选 a/b 都只升级人工，现场不动。组头还有「全部按账本修磁盘 / 全部按磁盘回写账本」的批量按钮（按工具整批处置）。

**② 快照不变量违背**：如「快照存在但无激活预设」等异常残留，逐条「一键修复」（即对该工具执行恢复默认）。

**③ 残留暂存条目**：未回移的暂存技能，逐条「回移」。

**④ 待确认专属建议**：见上文专属绑定一节；仅列出建议，不自动写入。

## 托盘快捷操作

系统托盘菜单中有「预设组」分区，适合不打开主窗口快速切换：

- 每个预设项**带勾选态**（当前在某工具上应用中即勾选）。
- **点击直接执行**，没有确认弹窗：未勾选 → 应用；已勾选 → 恢复默认。
- **通用预设**经子菜单先选工具再执行；工具私有预设为顶层项，点击直接作用于绑定工具。
- 执行成败写入日志，菜单随后重建以反映真实状态；失败时勾选态回到当前真实状态，可直接重试。

## 注意事项

- 预设应用/恢复会真实移动目录与改写工具配置。**首次体验或做手工测试前，请先备份 `~/.mam/` 目录**；也可以用隔离环境验证（`MAM_HOME` 环境变量可重定向数据目录，仅在开发/调试构建中生效）。
- 关闭预设 = 恢复默认，是幂等操作：没有激活预设时执行它不会产生任何改动。
- 白板模式只会「清场」不会启用任何东西，符合预期再确认。
