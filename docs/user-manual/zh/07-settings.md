# 设置选项

通知、轮询间隔、工具检测等设置

## 概述

本章介绍 设置选项 相关的功能和使用方法。

## 功能说明

MultiAgents Manager 提供完整的 设置选项 功能，支持用户高效管理 AI 编程工具。

## 远程接入

设置页的「远程接入」开启后，可以在其他设备的浏览器里访问本机的会话看板，提供局域网、临时隧道、自有域名、外部域名（免域名）四种通道，全部受四位**访问密码**保护。

**本机浏览器访问也需要访问密码**：从这台电脑自身的浏览器打开看板地址，与远程设备一视同仁——首次访问需输入一次访问密码，之后 180 天内免密码。

### 外部域名（免域名）通道

没有自己的域名，也能获得一个**永久不变**的访问地址：

1. 在本机安装 [Tailscale](https://tailscale.com/) 并登录一次（在浏览器里授权即可）
2. 在「远程接入」通道区选择「外部域名（免域名）」，按引导开通
3. 开通后得到形如 `https://<机器名>.<尾网名>.ts.net/m` 的地址——永久不变，换网络也能访问

应用会先校验地址可达性，通过后才显示可用地址；已生效后每分钟自动复验，异常时自动尝试恢复。

**带宽限制（该通道的已知特性，不是故障）**：走这条外部通道时带宽受限（实测下行约 1.8 Mbps、上行约 0.8 Mbps）——下载 20 MB 附件约 1.5 分钟，手机上传约 3.3 分钟，大文件会明显偏慢。想要满速，可以在手机上也装上 Tailscale，走尾网直连。

## 操作步骤

1. 打开应用主界面
2. 根据需要配置相关选项
3. 确认设置生效
